# IPTV Cast

Плеер ТВ-плейлистов (M3U/M3U8) для Android. Capacitor 8 + Vite, чистый JS.

**Приложение не содержит плейлистов и каналов.** Три вкладки:

- **Библиотека** — ваши плейлисты по жанрам, избранное, история. Плейлист загружается по ссылке, из файла
  или целой подборкой (готовые файлы по жанрам лежат в папке [`playlists/`](playlists/README.md)).
  Внутри плейлиста — список каналов с поиском и группами.
  - **Проверка** (кнопка «Проверить», или значок ✓ на карточке): плейлист скачивается, из него берутся до 10 каналов
    по всему списку, и каждый открывается как в плеере (для HLS — вплоть до первого сегмента). Нашёлся живой поток —
    плейлист валиден. Нет — приложение спрашивает, что делать: повторить, удалить или оставить; нерабочие можно удалить
    все сразу (с подтверждением). Результат виден на карточке.
  - **CRUD**: загрузить (ссылка, файл, подборка), создать свой пустой плейлист, изменить (название, значок, жанр,
    описание, адрес), удалить. В своих плейлистах так же создаются, правятся и удаляются каналы.
- **Плеер** — что играет сейчас: управление, показ на ТВ (Google Cast), таймер сна, недавние.
- **Настройки** — тема, язык, User-Agent, данные, проверка подключения.

Нажатие на канал сразу открывает окно плеера: видео, пауза, ✕ и системная «Назад», предыдущий/следующий канал,
шестерёнка с выбором качества; если поток не играет, в окне написана причина. Без уведомлений и фоновых служб.

## Сборка на GitHub

1. Залейте проект в репозиторий (ветка `main`), включая `android/`, `package-lock.json` и
   **`android/app/debug.keystore`** (публичный ключ подписи).
2. Actions → **Android build** → артефакт `IPTV-Cast-<версия>`; тот же APK публикуется в Releases
   (тег `v<версия>`). Секреты не нужны.

### Обновление поверх установленного

Все сборки подписаны одним постоянным публичным ключом `android/app/debug.keystore`
(пароль `android`, алиас `androiddebugkey`), поэтому новая версия **ставится поверх старой**.
Версия задаётся только в `package.json`: `0.1.0` → `versionCode 100`. Выпуск обновления:

```bash
npm run bump        # 0.1.0 -> 0.1.1  (или: npm run bump -- minor)
git commit -am "0.1.1" && git push
```

> Ключ публичный намеренно (период разработки). Любой, у кого он есть, может подписать
> «обновление» вашим ключом. Перед публикацией в Google Play включите Play App Signing
> и подпишите AAB своим закрытым ключом загрузки: задайте переменные
> `IPTV_KEYSTORE_FILE`, `IPTV_KEYSTORE_PASSWORD`, `IPTV_KEY_ALIAS`, `IPTV_KEY_PASSWORD`
> (или файл `android/keystore.properties`) — `release` подпишется ими, код менять не нужно.

## Локально

```bash
npm install
npm run dev        # интерфейс в браузере (нативных функций нет)
npm run sync       # vite build + cap sync
npm run android    # Android Studio
```

Нужны Node 22+, Java 21, Android SDK 36.

## Как устроено

| Часть | Файлы |
|---|---|
| Оболочка, вкладки, свайпы, «Назад» | `src/app`, `src/ui` |
| Жанры, подборки плейлистов (внешние файлы) | `src/data/types.js`, `playlists/*.json` |
| Парсер M3U (логотип, группа, User-Agent, Referer) | `src/iptv/parse.js` |
| Загрузка и кэш плейлистов (IndexedDB) | `src/iptv/playlist.js`, `src/core/kv.js` |
| Избранное, история, свои источники и каналы | `src/iptv/store.js` |
| Состояние воспроизведения, ТВ, таймер сна | `src/iptv/playback.js` |
| Окно плеера (Media3), очередь каналов, Cast | `android/app/src/main/java/com/iptvcast/app` |

Загрузка: вкладка «Библиотека» → **Загрузить** → ссылка (M3U или подборка `.json`), файл или один канал.

## Google Play: чек-лист

- targetSdk 36, minSdk 24, формат AAB.
- Описание и скриншоты без названий каналов и брендов; в приложении нет ни встроенных потоков, ни встроенных плейлистов (подборки лежат отдельными файлами в репозитории).
- Политика конфиденциальности (приложение данные не собирает), анкета Data safety, рейтинг, «Нет рекламы».
- Личный аккаунт разработчика: закрытое тестирование ≥12 тестеров × 14 дней перед production.
- Проверить на устройстве Android 16: «Назад», доступ к локальной сети для Cast, 16 KB page size.

## Передача на ТВ

Кнопка 📺 открывает окно выбора: **Chromecast / Google TV** (системный список) и **телевизоры DLNA** (Samsung, LG,
Sony, Philips и др.; ищутся по сети). Там же «Диагностика ТВ»: адрес телефона, сервисы Google Play, готовность Cast,
найденные DLNA-устройства.

- **Chromecast** получает поток через маленький прокси на телефоне: он добавляет CORS-заголовки (без них приёмник
  Chromecast отказывается играть почти любой IPTV-поток), подставляет нужные `User-Agent`/`Referer` и переписывает
  HLS-списки. Отключается в Настройках («Chromecast: передавать через телефон»).
- **DLNA**: ТВ берёт поток сам и напрямую (прокси включается, только если потоку нужны особые заголовки).
- Если ТВ не смог воспроизвести поток, приложение сообщает об этом и предлагает DLNA или внешний плеер.
- **Пока идёт передача через прокси, приложение должно оставаться запущенным** (фоновой службы и уведомления нет
  намеренно). С DLNA без прокси телефон после отправки можно убрать.

## Ограничения Cast

- Используется Default Media Receiver: надёжно играет HLS (`.m3u8`), «сырой» MPEG-TS на многих Chromecast нет
  (для таких потоков берите DLNA).
- Нужны сервисы Google Play; без них работает DLNA.
- Телефон и ТВ в одной Wi-Fi сети. targetSdk 36: защита локальной сети Android 16+ для таких приложений не включена;
  при переходе на targetSdk 37 понадобится разрешение `ACCESS_LOCAL_NETWORK`.
