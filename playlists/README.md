# Подборки плейлистов

Приложение **не содержит плейлистов**. Здесь лежат готовые подборки по жанрам: это списки ссылок на открытые
плейлисты сообществ [iptv-org](https://github.com/iptv-org/iptv) и [Free-TV](https://github.com/Free-TV/IPTV).
Загружаются в приложение сами, когда вы этого захотите.

| Файл | Что внутри |
|---|---|
| `sport.json` | спорт, экстрим |
| `news.json` | новости, погода, бизнес, парламенты |
| `movies.json` | кино, сериалы, классика |
| `kids.json` | детские, анимация, семейные |
| `music.json` | музыка, релакс |
| `docs.json` | документальные, наука, образование, культура |
| `fun.json` | развлечения, комедии, общие, телемагазины |
| `life.json` | лайфстайл, кулинария, путешествия, авто, религия |
| `countries.json` | 32 страны |
| `languages.json` | 12 языков |
| `mix.json` | общие подборки: все каналы, Free-TV, общественное ТВ |
| `all.json` | всё вместе (75 плейлистов) |

## Как загрузить

**По ссылке.** Библиотека → «Загрузить» → «Ссылка», адрес файла в вашем репозитории:

```
https://raw.githubusercontent.com/<вы>/<репозиторий>/main/playlists/sport.json
```

**Из файла.** Скачайте нужный `.json` на телефон → Библиотека → «Загрузить» → «Файл».

Плейлисты, которые уже есть в библиотеке, повторно не добавляются.

## Формат

```json
{
  "format": "iptvcast-pack",
  "name": "Спорт",
  "playlists": [
    {
      "name": { "ru": "Спорт", "en": "Sports" },
      "desc": { "ru": "Описание", "en": "Description" },
      "url": "https://iptv-org.github.io/iptv/categories/sports.m3u",
      "type": "sport",
      "emoji": "🏆"
    }
  ]
}
```

- `name`, `desc` — строка или объект `{ru, en}`; `desc` необязателен.
- `type` — жанр: `mix`, `sport`, `news`, `movies`, `kids`, `music`, `docs`, `fun`, `life`, `world`.
- Подойдёт и просто массив таких записей, без обёртки.
- Свою подборку можно собрать так же: любой `.json` в этом формате загружается тем же способом.
