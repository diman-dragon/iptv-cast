# Тесты

- `run-java-tests.sh` — нативная логика без Android: проверка потока (`Prober`), прокси для ТВ (`StreamProxy`,
  `HlsRewriter`), управление DLNA-телевизором (`Dlna`). Поднимает тестовые HTTP-серверы, 41 проверка.
- `ui/*.mjs` — сквозные сценарии интерфейса в jsdom: проверка каждого канала с автоудалением, откат, защита от «нет
  интернета», CRUD плейлистов и каналов, передача на ТВ, загрузка подборок. Нужны `npm i jsdom fake-indexeddb` вне
  проекта; пути к `src/` в начале файлов поправьте под себя.
