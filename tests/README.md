# Тесты

- `run-java-tests.sh` — нативная логика без Android: проверка потока (`Prober`), прокси для ТВ (`StreamProxy`,
  `HlsRewriter`), управление DLNA-телевизором (`Dlna`). Поднимает тестовые HTTP-серверы, 41 проверка.
- `ui/*.mjs` — сквозные сценарии интерфейса в jsdom (проверка плейлистов, CRUD, ТВ, загрузка подборок).
  Нужен `npm i jsdom` вне проекта; пути к `src/` в начале файлов поправьте под себя.
