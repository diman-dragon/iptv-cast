# Описание для Google Play (ru-RU)

**Название:** IPTV Cast

**Краткое (80):** Плеер ТВ-плейлистов: каталог бесплатных источников и показ на ТВ.

**Полное:**
IPTV Cast — плеер для M3U-плейлистов. Каталог бесплатных публичных списков по темам: спорт, новости, кино, детям,
музыка, познание, развлечения, лайфстайл, страны и языки. Добавляйте свои плейлисты по ссылке или из файла.
Избранное, история, таймер сна, звук в фоне, картинка в картинке и показ на телевизор по домашней сети (Google Cast).

Приложение не содержит каналов и не предоставляет контент: вы сами выбираете источники.
Без рекламы, без аккаунта.
